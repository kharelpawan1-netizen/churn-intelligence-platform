# API Documentation

Full interactive documentation (auto-generated by FastAPI): `/docs`

## Authentication
All endpoints except `/health` and `/monitoring/summary` require an `x-api-key` header.

## Endpoints

### `GET /api/v1/health`
No auth required. Returns service status.

### `POST /api/v1/predict`
Requires `x-api-key` header. Body: full customer record (see `CustomerData` schema in `/docs`). Returns:
```json
{
  "churn_probability": 0.1103,
  "will_churn": false,
  "risk_level": "low"
}
```
`risk_level` is `"low"` (< 0.2), `"medium"` (0.2–0.5), or `"high"` (≥ 0.5).

### `GET /api/v1/monitoring/summary`
No auth required. Returns aggregate stats on all predictions made so far: total count, average churn probability, breakdown by risk level.
